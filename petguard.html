PETGUARD

PetGuard is a web design project for a pet grooming website featuring custom spot illustrations and a clean, user-friendly layout designed for dog owners.

PROJECT OVERVIEW

The goal of this project was to create a grooming website that feels friendly, approachable, and easy to navigate while still highlighting the custom illustrated brand personality.
